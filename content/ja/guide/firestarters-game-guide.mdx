## まずはここから：FIRESTARTERSとは何か

FIRESTARTERSのゲームガイドを探しているなら、まず知っておくべきことがある。これはマップを探索して物資を漁るルート系シューターではない。モメンタム、攻撃的な狩り、スコア追求を軸にした高速アーケード移動シューターであり、2026年10月28日にSteam早期アクセスを開始した時点では、最初のエピソードしか含まれていなかった。

これが重要なのは、現在書かれているガイドの多くが未完成のゲームを説明しているからだ。Studio Kerosene自身の早期アクセスに関する注記には、エピソード1にはストーリーモードの冒頭部分とアンロック可能なアーケードモードが含まれ、基本のゲームプレイ、ストーリー、戦闘システムはすでに機能しているが変更される可能性があると述べられている。開発者はバージョン1.0までに早期アクセスで18～24か月を見積もっており、全部で4つの「エピソード」を予定している。

したがって、以下の内容はすべてエピソード1のスナップショットとして扱い、[FIRESTARTERS公式Steamストアページ](https://store.steampowered.com/app/3733710/FIRESTARTERS/)とローンチ期間の報道で確認したものだ。

### 設定を1段落で

プレイヤーはKeraを操作する。彼女は沖縄の裏路地出身の元不良で、現在は犯罪シンジケートがライブ配信する日本の剣闘血闘競技「STEEL」に出場する囚人だ。彼女は、自由を賭けて戦う囚人チーム「Firestarters」の代表ファイターである。戦いの合間には、ビジュアルノベル風のカットシーンが物語を進める。

## まずは移動：スケート、スライド、グラインド、グラウンドパウンド

Steamページでは、STEELのアリーナをスケートパークのように説明している。各空間をスケート、スライド、グラインド、グラウンドパウンドで駆け抜けながら、機械化された爪を避けるのだ。Keraの装備は、性能を強化するSTEELバトルスーツとカスタムのロケットスケート一対だ。

[Coloured Static Press](https://colouredstaticpress.com/firestarters-hands-on-preview-steam-early-access-studio-kerosene/)のハンズオンプレビューでは、アリーナがレール、ランプ、急カーブで構成され、明るいトレーニング空間と赤い照明の工業風インテリアに分かれていると説明されている。重要なのは、これらのエリアが移動するために設計されており、遮蔽物として使うためのものではないという点だ。立ち止まって撃つシューターのように遊ぶと、設計に逆らうことになる。

今すぐ実践できるポイント：

- **キルとキルの間も動き続ける。** スコアシステムは持続的なペースを評価するので、部屋を片付けて休むのではなく、遭遇戦を連続させよう。
- **必要になる前にレールのラインを覚える。** グラインドとスライドは単なる見せ場ではなく、移動のためのツールだ。
- **アリーナの再挑戦は前提。** プレビューでは、各アリーナをターゲットのチェックリストとして扱うのではなく、もう一度挑む理由としてスコアリングループが挙げられている。

正確なキーバインドや入力割り当ては入手可能な資料には記載されていないため、二次情報の割り当てに頼らず、ゲーム内の操作メニューを確認してほしい。

## 戦闘ループ：体力・アーマー・弾薬のピックアップはなし

これはぜひとも身につけるべき、最も重要なルールだ。Steamページによると、STEELのアリーナには体力、アーマー、弾薬のピックアップが一切存在しない。資源は倒したアンドロイドから得る——倒したものから必要なものを奪うのだ。

リード開発者のAlex Harteはローンチ時の取材で率直にこう述べている。アリーナに安全網はなく、狩ることが生存への道だと。この一つの設計判断が、すべての戦闘への向き合い方を大きく変える。

- **攻撃こそ防御。** 敵から後退すると、後退によって守ろうとしていた資源を自分で絶つことになる。
- **エイムよりもキル順が重要。** 脅威に見える敵ではなく、到達してとどめを刺せる敵を優先する。
- **6つの武器と自己完結する銃撃。** ストアページには6つの武器のアーセナルが記載されており、射撃を続けるためにピックアップに依存しない設計だ。
- **温存しない。** 弾薬はキルから得られるため、満タンのマガジンを抱えたまま交戦を避けて過ごすのは差し引きで損だ。

## アーケードモードとスコア争い

エピソード1の構造はシンプルだ。ストーリーモードで初めてストームをクリアし、その後アーケードモードで同じストームに戻り、公式ハイスコアを目指す。

Steamページでは、遭遇戦をクリアするだけでは挑戦の一部にすぎないと明言されている——観客はより速いキルとより高いスコアを求めている。プレビュー版では残り敵数、スコア、倍率が画面上で追跡されており、撮影映像にはシンクロメーターも確認できた。リーダーボードはグローバルなので、長期的な競争が繰り広げられるのはスコアリングの層だ。

実際には次のことを意味する：

1. まずストーリーモードのクリアを済ませ、アーケードへの参加をアンロックする。
2. 序盤のアーケード挑戦は、完璧なスコアを追うのではなく、敵の出現の流れを覚えるために使う。
3. 自分のベスト、次にSteamフレンド、そしてグローバルボードと比較する——開発者はまさにこの順序で上達を位置づけている。

## PC要件と視認性に関する注意

システム要件は異例なくらい軽いが、開発者は最終版ではないとしている：

- **最低：** Windows 10、4コアCPU（Intel i3またはAMD Ryzen 3）、2 GB RAM、DirectX 12、1 GBストレージ
- **推奨：** Windows 11、6コアCPU（Intel i5またはAMD Ryzen 5）、2 GB RAM、1 GBストレージ

実用的な注意点が一つ、Coloured Static Pressのハンズオンセッションから挙げられている。印象的な赤い工業風アリーナでは、密度の高いHUD、強烈なエフェクト、同時多発する警告が、アクションが加速したときに注意を奪い合うことがある。彼らの提案は、アリーナ自体の視認性も、明確なスコアフィードバックに追いつく必要があるというものだった。脅威を見失うことがあるなら、それは個人的な失敗ではなく、現行ビルドにおける設計上の緊張関係だ。

また、ストアページには点滅光やストロボ効果に関する光過敏症への警告と、血、激しい暴力、強い言葉遣い、成人向けおよび示唆的なテーマ、喫煙を扱う成人向けコンテンツの説明がある。

## よくある質問

**FIRESTARTERSの武器アンロックに関するゲームガイドはある？**
まだない。また、確認済みの資料には武器アンロックシステムの説明がない。Steamページは6つの武器のアーセナルに言及しているが、進行方法の詳細はないため、現在オンラインで見かけるアンロック一覧は未確認だ。

**アーケードモードをプレイする前にストーリーモードをクリアする必要はある？**
はい。アーケードモードはアンロックされるコンテンツで、Steamページには、ストーリーで初めてストームをクリアした後にアーケードモードでそのストームに戻ると記載されている。

**体力と弾薬はどこで手に入る？**
倒したアンドロイドからだ。STEELのアリーナには体力、アーマー、弾薬のピックアップが配置されていない。だからこそ、攻撃的なプレイが意図された生存戦略なのだ。

**ゲームは完成している？**
いいえ。エピソード1が最初の早期アクセスリリースであり、バージョン1.0までに追加3エピソードが早期アクセス購入者向けの無料アップデートとして予定されている。
